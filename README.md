# assistant-kit

Ton assistant personnel, installé par ton propre Claude Code.

1. Ouvre Claude Code dans un terminal (`claude`, connecté avec ton compte).
2. Colle le lien de ce dépôt et dis : **installe**.
3. Réponds aux questions, une à la fois (la valeur par défaut est donnée, Entrée suffit).
4. Quand il te donne une commande qui commence par `!`, tape-la toi-même (c'est la seule chose à faire à la main).
5. À la fin, `ultron` ouvre ta première session avec ton assistant.
